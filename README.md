## 🎯 Core Operating Principles
- **Proactive Communication:** Anticipating client needs, flagging scheduling bottlenecks, and providing clear daily status updates.
- **Data Integrity & Confidentiality:** Adhering strictly to POPIA/GDPR regulations when handling medical, legal, and financial records.
- **Process Standardization:** Turning repetitive tasks into documented, repeatable workflows to save executive time.
